# Mesh 前端静态原型

这是 Mesh 工作区的可交互、零依赖静态蓝图。直接双击 `index.html` 即可浏览，不需要安装依赖或启动服务器。

## 页面覆盖

- 登录、注册与验证码状态
- 工作区切换、创建与设置
- 收件箱、聊天、我的工作
- Issue 列表、Issue 详情、看板与拖拽
- 项目、成员名册、智能体
- Skill、自动化、分析与设置
- 空态、加载态、错误态展示
- 桌面与移动响应式布局
- 亮色、暗色与跟随系统主题

## 交互入口

- 点击左侧导航或移动端底栏切换页面。
- 按 `⌘/Ctrl + K` 打开全局命令面板，按 `C` 新建 Issue。
- 在看板中拖动卡片跨列移动。
- 点击右上角主题按钮切换亮暗主题。
- 点击工作区名称切换或创建工作区。
- 页面路由写入 URL hash，可直接收藏或分享相对入口。

全部界面结构、样式组织、交互脚本、图标与 Mesh 标识均为本目录内的原创实现。

## 浏览器冒烟测试

仓库维护者可用 Chrome DevTools 协议运行零依赖交互检查：

```bash
google-chrome --headless --no-sandbox --remote-debugging-port=9222 \
  "file://$PWD/index.html#/issues"
node smoke-test.mjs
```
