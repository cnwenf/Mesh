## 静态盘点记录

- `App.tsx` 中 46 个 `<Route>` 节点，45 个 `*Page.tsx` 页面文件。
- 26 个产品 CSS 文件中，仅 4 个包含宽度响应式断点。
- 基础主题共有 52 个 token，但字号仅 3 档、圆角仅 3 档、阴影仅 1 档、时长仅 2 档。
- `Sidebar` 暴露 `/skills`，但应用路由树没有挂载技能列表、市场和详情页。
- 顶栏搜索框只有聚焦能力，没有检索、提交或打开命令面板的行为。
- 768px 以下侧栏直接 `display:none`，没有抽屉、底部导航或其他等价入口。
- 设计系统已有 480 处无障碍相关标记、forced-colors 适配、reduced-motion、对比度检查和统一状态组件，这些能力应保留并扩展。

## 复查边界

- 确定性 mock 适合视觉和交互回归，不代替生产数据量、弱网、超长文本和真实权限组合测试。
- 已有功能验收截图不是本轮全部重跑；本轮以 53 个实际浏览器用例、代码盘点和当前基线截图共同形成审查证据。
- 后续实施必须在 320px、390px、768px、1024px、1440px 五档补齐全页矩阵，并加入真实长文本、空态、错误态、权限态和离线态。
