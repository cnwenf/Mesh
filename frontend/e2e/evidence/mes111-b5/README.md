# MES-128 / MES-111 batch ⑤ evidence

The `mes128-axe.spec.ts` production-preview crawl writes the deterministic evidence matrix in this directory.

- Pages: login, workbench, issue list, board, issue detail, members, chat, execution detail,
  inbox, autopilots, integrations, insights, settings (the §13.5 core registry).
- Layouts: mobile 390×844 and desktop 1440×900.
- Themes: light and dark.
- Matrix: 13 pages × 2 layouts × 2 themes = 52 screenshots. `manifest.json` is the
  machine-readable contract; the evidence gate rejects missing, stale, wrong-width, or duplicate files.
- Additional non-screenshot checks: 320px, 390px, and 640px (1280px at 200% reflow equivalent) page overflow; coarse-pointer 44×44px controls; axe WCAG A/AA on desktop and touch phone.
- Screen-reader manual review: NVDA/VoiceOver follow-up remains listed in `docs/audits/mes128-state-accessibility-matrix.md`; automated axe cannot replace that human check.

All images are generated by a fresh production build with `reuseExistingServer: false`. Run:

```sh
npm run test:e2e:a11y
npm run check:evidence
```
